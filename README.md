# VirtuCasa – Interior Design Studio Website

A production-ready portfolio website built for an interior design and custom furniture manufacturing studio.

## Tech Stack
- React (Vite)
- Tailwind CSS
- React Router
- Google Fonts
- Vercel (Deployment)

## Features
- Cinematic hero video  section
- Dynamic project pages
- Responsive design (mobile-first)
- SEO optimized (meta tags, sitemap, robots.txt)
- Custom domain deployment
